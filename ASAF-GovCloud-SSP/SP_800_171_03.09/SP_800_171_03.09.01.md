# SP_800_171_03.09.01 - \[Personnel Security\] Personnel Screening

## Control Statement

- \[SR-03.09.01.a\] Screen individuals prior to authorizing access to the system.

- \[SR-03.09.01.b\] Rescreen individuals in accordance with [conditions].

## Control Assessment Objective

individuals are screened prior to authorizing access to the system.
individuals are rescreened in accordance with the following conditions: [conditions].

## Control guidance

Personnel security screening activities involve the assessment of the conduct, integrity, judgment, loyalty, reliability, and stability of an individual (i.e., the individual’s trustworthiness) prior to authorizing access to the system or when elevating system access. The screening and rescreening activities reflect applicable federal laws, Executive Orders, directives, policies, regulations, and criteria established for the level of access required for the assigned position.

### This System

**Primary Path (Azure Government — Inherited):**
For ASAF deployments in the customer Azure Government tenant, personnel security for Azure Gov infrastructure staff is managed under Microsoft's PRIVA (Personnel Reliability and Identity Verification Assurance) program. All Azure Government employees with physical or logical access to government infrastructure undergo US government-equivalent background screening. This satisfies 03.09.01 for the infrastructure layer. Evidence: Azure Government FedRAMP System Security Plan, available via FedRAMP marketplace package FR1703088554.

**SecRed Personnel (VPS and System Access):**
All SecRed Knowledge Inc. personnel with SSH or administrative access to the VPS are subject to personnel security screening. Current status: screening process initiated, formal documentation in progress (POA&M B-4, target Sprint 37). ODP A.03.09.01.ODP.01 value: Annually and upon role change.

**Third-Party Provider Personnel (Hostinger):**
Hostinger data center staff have physical access to VPS hardware. Hostinger operates under ISO 27001 and GDPR frameworks which include personnel vetting procedures; however, formal equivalency to NIST 03.09.01 has not been independently verified. Contractual prohibition on unauthorized staff access to SecRed VPS hardware is being negotiated (POA&M B-3).

**POA&M Reference:** B-4 (SecRed personnel screening documentation — Sprint 37)
